# AgentForge / 智能体锻造工坊

> 从零锻造一个可理解、可改造的 AI Agent。

AgentForge 是一个面向学习与实战的开源项目：不直接封装现成 Agent 框架，而是从最小内核开始，逐步实现工具调用、记忆、规划、多步执行、可观测与评测。每一层都尽量保持简单、透明、可替换，帮助你真正理解 AI Agent 是如何运转的。

## 为什么做 AgentForge？

市面上的 Agent 框架很多，但“会用”不等于“会造”。AgentForge 希望回答一个问题：

**如果从零开始，我该如何锻造一个 AI Agent？**

项目采用渐进式路线：

- 先跑通最小 Agent Loop
- 再加入工具调用
- 再加入记忆与状态
- 再加入规划与任务分解
- 最后补齐可观测、评测与多 Agent 协作

每一阶段都对应可运行代码与说明文档，适合学习、教学、二次开发和工程实践。

## 核心特性

- **从零实现**：不依赖重型 Agent 框架，核心逻辑透明可读
- **渐进式构建**：按阶段实现最小内核、工具、记忆、规划、评测
- **可插拔设计**：LLM、工具、记忆、规划器均可替换
- **可观测**：记录每一步思考、工具调用与执行结果
- **可评测**：提供任务集与评测脚本，衡量 Agent 表现
- **面向实战**：不仅讲概念，也提供可运行示例与工程结构

## 架构模块

```text
AgentForge
├── http          # 网络请求
├── docs          # 学习记录文档
├── tools         # 工具注册、调用与权限控制
├── memory        # 短期/长期记忆
├── planner       # 规划与任务分解
├── runtime       # 运行环境与执行沙箱
├── observability # 日志、追踪与可视化
├── evals         # 任务集与评测
└── examples      # 从最小 Agent 到完整 Agent 的示例
```
